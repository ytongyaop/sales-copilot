# ADR-0002：前后端分离（FastAPI + Vue3）

- **状态**：已接受
- **日期**：2026-11-13
- **背景**：演示要证明的东西里，有两条只能靠"接口与界面的分离"才看得出：打开 `/docs` 能看到接口文档；把后端停掉，前端显示看得懂的业务语言错误而不是白屏。此外仪表盘四个数字必须与操作时间对得上，界面不能自己猜数据。
- **选项**：
  - A：FastAPI 后端 + Vue3 前端，前后端只走 HTTP/JSON
  - B：Streamlit 一体式 —— 一周内明显更快，但界面与逻辑耦合在一个进程里，没有 API 契约可演示，失败时容易白屏或直接暴露原始报错
- **决策**：选 A。后端是唯一真源与唯一校验权威，前端只做展示与入参收集。
- **后果**：
  - 变好：API 契约可演示（`/docs`）、前端可整体替换、报错有明确映射落点、仪表盘数字一定来自后端。
  - 变差：前端多花 15–20 小时；为守住一周窗口，砍掉报价审批流、排课、CSV 对照模板等（它们本来也不验证引擎）；前端不得缓存业务数据，每次操作要回落后端，页面比"本地缓存版"多一点请求。
  - 要还的债：前后端契约靠 `docs/` 与接口文档维持，接口一改必须同步前端，v1 不引入代码生成。
- **确认方式**：跑起服务后打开 `/docs` 能看到接口列表；把后端进程停掉，前端显示业务语言错误；仪表盘任一数字变化都能对应到一次已提交的操作记录。
